#Privacy Policy - Discord Server

On Harvest's Discord server we use Ban Reaper, a moderation bot that helps enforce server verification rules.

  • The bot only processes member join dates and roles to identify unverified users.
  • No user data is logged long-term or shared with third parties.
  • There is no opt-out for moderation actions, as verification is required by the server rules.
